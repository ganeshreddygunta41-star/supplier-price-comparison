# Supplier Price Comparison

This Python script compares two sample supplier quotes by calculating the price per kilogram. It prints both prices and identifies the cheaper supplier or reports a tie.

## How to run

Open a terminal in the folder containing `compare_prices.py` and run:

```bash
python compare_prices.py
```

## Example output

```text
Supplier A: $12.00 per kg
Supplier B: $10.00 per kg
Supplier B is cheaper per kg.
```

To try different quotes, change the prices and pack sizes in the script.
